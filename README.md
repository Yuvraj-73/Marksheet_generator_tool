# Student Marksheet Generator

A GUI-based Student Marksheet Generator built using Python, Tkinter, and FPDF.  
This project allows users to enter student details and marks, automatically calculate percentage and grades, and generate a downloadable PDF marksheet.

---
## Features

- Student details input
- Marks entry for multiple subjects
- Automatic total and percentage calculation
- Grade generation system
- Pass/Fail result calculation
- PDF marksheet generation
- Simple GUI using Tkinter

---
## Technologies Used

- Python
- Tkinter
- FPDF

## Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/marksheet-generator.git
```

### 2. Navigate to Project Folder

```bash
cd marksheet-generator
```

### 3. Install Required Library

```bash
pip install fpdf
```

---
## Run Project
```bash
python main.py
```

---
## How It Works

1. Enter student details
2. Enter subject marks
3. Click Generate Marksheet
4. PDF marksheet gets automatically created
